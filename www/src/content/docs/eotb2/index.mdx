# Eye of the Beholder II — The Legend of Darkmoon

The DOS/VGA release is the active target for EOB2. Its `.DCR`, `.DEC`, `.EGA`,
`ITEM`, `TEXT`, level and wall formats are confirmed against the real corpus,
and a working DOS first-person walker is integrated. The Amiga directory is
reference material only at present.
