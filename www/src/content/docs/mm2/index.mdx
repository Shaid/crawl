# Might & Magic II — Gates to Another World

MM2 is integrated from a finished ground-truth reverse-engineering project.
Crawl's TypeScript codecs are original implementations informed by the cited
format documents, not ports of the reference C/Python code.

The retail Amiga corpus now has verified decoders for the `.dat` records, `.32`
image sheets, `.anm` television animations, maps, events, roster, monsters,
items, spells, strings and the globe text. The DOS `.4`/`.16` graphics path is
also integrated and byte-compared against the reference implementation.
