# Eye of the Beholder

EOB1 is a two-platform Kyra-family investigation. Amiga and DOS/VGA resources,
palettes, wall tiles, decorations, levels and event data are substantially
decoded, and a bespoke per-tile compositor now powers the Amiga first-person
walker.
