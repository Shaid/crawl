| mm3-mon-rle | **closed** | DOS sprite scanline RLE is NOT the Xeen grammar. Three commands only: `0x00-0x7F` literal run of `op+1` bytes; `0x80-0xBF` transparent skip of `(op&0x3F)+1`; `0xC0-0xFF` run of `(op&0x3F)+3` of the following byte. Line framing confirmed as `u16 lineLength` + `u16 xSkip` (xSkip is a real u16, often non-zero — only its high byte is always 0). Decoder found and disassembled in the `MM3.CC` `vga` display driver (entry 0x8F99), API entry 7 `vga`+0x0E92 → dispatcher `vga`+0x1D70 → row loop `vga`+0x1DC2-0x1E20; 9 blit variants (incl. horizontal mirror via flag bit 0) share the byte-identical opcode core. End-of-line truncation **refuted** — the loop exits only on `cmp si,bp / je`. Verified: **157,330/157,330 lines and 3,823/3,823 cells consume exactly (402 files, zero deviation)**; **0/157,330 lines exceed the cell width**; `archer.mon` 5/5 Amiga frames 0 mask mismatches; `.fac` 43 DOS-only px / 156,667 (0.027%).
