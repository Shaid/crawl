# Palettes & Accent Ramps

The dungeon runs in 6-bitplane EHB: 32 hardware colour registers, with 32–63
generated by hardware as half-intensity copies. The copper list that installs
them is built in `bcdfp` (`LAB_00BD`).

## One fixed core + a swappable accent ramp

Eight 32-word palettes exist across the game files. Comparing them shows a
**fixed core** — indices `0`, `16`, `17`, `18`, `20`–`25` are byte-identical in
every variant — while **only indices 19 and 26–31 change**. Those six changing
indices (26–31) are the **accent ramp**.

| File | Offset | idx 19 | idx 26–31 | Character |
|------|--------|--------|-----------|-----------|
| `bcdfp` | `0x004194` | `033b`→`0020` | `0b30 0c40 0d51 0e62 0f73 0f84` | orange / fire |
| `bcdfq` | `0x0002c6` | `033b` | `0b60 0c70 0c80 0d90 0eb0 0fc0` | gold |
| `bcdfu` | `0x0003ec` | `033b` | `0432 0542 0653 0764 0875 0986` | brown |
| `bcdfu` | `0x00042c` | `033b` | `0223 0334 0445 0647 0858 0968` | blue-grey |
| `bcdfu` | `0x00046c` | `033b` | `0332 0443 0654 0987 0ba8 0eeb` | **stone / olive** |
| `bcdfu` | `0x0004ac` | `033b` | `0222 0333 0444 0555 0666 0777` | neutral grey |
| `bcdfu` | `0x0004ec` | `033b` | `0234 0345 0456 0678 089a 09ab` | blue |
| `bcdft` (decompressed) | `0x01e886` | `0fd0` | `0332 0443 0654 0987 0ba8 0eeb` | stone / olive |

## The accent ramp varies per dungeon level

The table above is a census of *copies*. The authoritative ramp table lives in
the decompressed `bcdft` image at **S_1 `+0x27B00`** and has **12 entries of 12
bytes** (6 words = COLOR26–31, one per dungeon level). The five `bcdfu` records
are entries 0–4 duplicated into the epilogue overlay.

`SetDungeonPalette(index)` (S_1 `+0x26900`) writes the chosen ramp into the
copper list at `$510(A5) + 0x6A` (= COLOR26).

Per-level defaults (13 words at `bcdft` S_2 `+0x39E`):

```
0,0,0,0, 1,2,2,2,2,2,2,3,3
```

Overrides: a map-square flag bit 31 forces ramp 4, and `bcdfs` action opcodes
`0x1E`/`0x1F` set it from the action record's byte `0x06`.

## The tileset ↔ ramp correlation

Because the tileset file is also chosen per level, ramp and tileset correlate:

| Tileset | Ramp | Levels |
|---------|------|--------|
| `bcdfx` | 0 (tan) / 3 (grey) | 1–4 / 12–13 |
| `bcdfy` | 1 (violet) | 5 |
| `bcdfz` | 2 (bone/cream) | 6–11 |

map 7 (47% of pixels), map 8 (31%), map 6 (3%), map 11 (0.5%), map 4 (0.3%).

## A common pitfall

There is **no separate "monster palette"**. Monsters and walls necessarily share
one EHB palette. The old `bcdfu` file offset `0x2C6` claim was wrong — that
offset lands inside the library-name strings.
