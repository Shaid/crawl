# MM2 test fixtures

Tiny binary artifacts copied from the **Vairn/MM2** ground-truth repo
(https://github.com/Vairn/MM2) to anchor the codec tests. **No retail game data**
is stored here — these are either generated test output or decoder output.

| File | Origin | What it anchors |
|------|--------|-----------------|
| `roster_create_test.dat` | `game/test_out/` — generated by the Vairn C++ remake's roster-create test | Full 8320-byte Amiga-format roster; `tools/mm2/__tests__/roster.test.ts` decodes "Sir Felgar" and round-trips byte-exact |
| `anm_decoded/51/meta.json` | `game/EXTRACTED/anm_decoded/51/` — `tools/decode_anm.py` output for the retail `51.anm` | Exact image-chunk offset, per-frame RLE consumption, sequence blocks, prelude, palette — the structural anchor for `anm.ts` |
| `anm_decoded/51/frame_*/plane*.bin` | same | The ground-truth decoder's raw bitplane output; our decode of the retail `51.anm` must match byte-for-byte (`tools/mm2/__tests__/real-data.test.ts`) |

The retail files these fixtures describe (`51.anm`, a real `roster.dat`) live in
`data/mm2/amiga/data/` on machines that have them (gitignored); the
`real-data.test.ts` suite skips when they're absent.
