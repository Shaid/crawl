# Eye of the Beholder III — Assault on Myth Drannor

EOB3 is built on the AESOP/16 runtime rather than the simpler native code paths
used by the earlier EOB investigations. Its resource containers, bitmap
palettes and many graphics are decoded, while the first-person dungeon view has
been identified as a real tile/depth compositor whose dispatch lives in
interpreted bytecode.
