# Lands of Lore — The Throne of Chaos

Lands of Lore uses Westwood/Kyra resource conventions but has its own 3-D
dungeon pipeline and palette rules. The repository has a real-art first-person
renderer, decoded level files, Kyra containers, EMC2 disassembly and a
confirmed embedded level palette mechanism.
