## Status vocabulary

- **Reference** — the deepest curated docs and extraction evidence in the site.
- **Active** — core formats and/or a viewer are working, with bounded follow-on
  research still in progress.
- **Extracted** — the important shipped data is decoded and browsable; the next
  work is coverage, visual verification or a narrow unresolved format question.
- **Research** — substantial real evidence exists, but a major engine or
  palette question still blocks the next layer.

The bottom eight rows are the Amiga-family crawlers first explored on
2026-11-21: each has had one reconnaissance pass, and Zombi, both Abandoned
Places games and Crystal Dragon have had a first extractor. The repository
also has an uncurated backlog — Ishar and the SSI collection. Those are
intentionally not represented as active projects until they have their own
status surfaces.
