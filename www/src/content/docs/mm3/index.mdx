# Might & Magic III — Isles of Terra

MM3 spans the Amiga `.cc` archives and the DOS `MM3.CC` archive. Both container
codecs, filename hashes, sprite records, screens, palettes and maze records are
decoded; the shared viewer integration is already wired for both platforms.
