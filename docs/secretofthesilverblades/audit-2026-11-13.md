# Secret of the Silver Blades (Amiga): gap audit, 2026-11-13

Report-only audit, 2026-11-13. None of these corrections have been applied yet. It was run by an
independent codebreaker re-derivation (own GLIB parser and method-5 decoder written from the spec,
plus read-only use of the repo decoders) over the four Gold Box Forgotten Realms titles; this page
carries the findings that touch Secret of the Silver Blades. Sibling pages:
`docs/poolofradiance/audit-2026-11-13.md`, `docs/curseoftheazurebonds/audit-2026-11-13.md`,
`docs/poolsofdarkness/audit-2026-11-13.md`.

## Summary verdict

- Containers, codecs, GEO grid and WALLDEF geometry hold up.
- The 8x8 tile format is wrong; every shipped Secret wall texture (`walldef*-view6.png`, 161) is
  wrong pixels.
- The "2 truncated files" status is stale: all files decode.
- The ECL wallset-binding coverage claim is overstated: 15 of 51 slots are the 127 placeholder, and
  some levels use those slots.
- Biggest risk: circular visual confirmation of the 1bpp decode, plus a walker that falls back to
  placeholders on Secret levels 16 and 80-82.

## Claims wrong or overstated

### 1. WRONG: the 8x8 "1bpp, 8 bytes per tile" format (highest impact)

- **Docs say.** Header-less 1bpp MSB-first tiles, one walldef byte = one tile:
  `goldbox-glib-format.md:336` and section 5.7 (:360-390); code
  `tools/shared/goldbox-walltiles.ts:93` (`decode8x8Tiles`).
- **Audit found.** Each "TILE" sub-block is an 8-byte header + P bitplanes, plane-major. Header:
  `u16 height=8, u16 x, u16 y, u8 widthBytes=1, u8 flag`. 48 B = 5 planes (Curse/Secret walls and the
  universal bank 203); 40 B = 4 planes (bank 202). The grammar fits Secret 1395/1395 glyph blocks.
- **Index mapping.** 0 = none, 1-45 = universal glyphs 0-44, then 46 + 70*slot + k.
- **Evidence.** Family seam-continuity oracle: Curse corrected 0.584 vs null 0.201 (lift 0.48),
  versus 0.655 vs 0.621 (lift 0.09) for the shipped reading. Cross-title: 31/45 universal glyphs
  share colour partitions with PoR.
- **Consequences.** Section 5.6's correction was never propagated to the code; the module doc
  (~line 66) still says the question is open. Circular "crenellation / door / herringbone"
  confirmations.
- **Fix.** New glyph decoder, rebuilt bank, re-render with the seam and cross-title oracles. Retire
  the Secret section 3a "flat bank" render (bank 202 is a 4-plane UI/arrow glyph set, not wall art).
  Add row `goldbox-glyph-format`.

### 2. Stale status: "truncated" files

- **Docs say.** Secret `data-structure.md:34-43` and `:228`: 19/21 OK, 2 truncated.
- **Audit found.** The GLIB section 3 correction and the shipped `container-directory.json` report
  21/21 OK, with `compressedTopLevel` 2. The audit's own decoder decompresses all 7 compressed files
  family-wide to valid bodies with 0 or 1 bytes left over.
- **Fix.** Update the status text.

### 3. OVERSTATED: ECL wallset-binding coverage

- **Docs say.** "17/17 levels, 51 slots" (Secret); GLIB `:681-691` and `:860-869`: every level that
  resolves at all resolves all 3 slots.
- **Audit found.** 15 of Secret's 51 slots are set to 127. Levels 16 (`21,127,127`) and 80/81/82
  (`3,127,127`) use slots that are 127, so the walker falls back to the placeholder there.
- **Hypothesis, cheap to test.** Loading a multi-wallset WALLDEF entry fills the following slots
  too. Entries 21 and 3 each have 3 wallsets, and every flagged level fits this pattern.
- **Fix.** Count 127/255 as unresolved; row `goldbox-ecl-multiwallset-slotfill`; test against
  levels 16 and 80-82.

### 4. Stale text and contradictions

- GEO planes 0/1 heading at `:183` still says "remain open, escalated" despite a correction block.
- The Secret `TODO.md` paths-tried rows still say "Pending at time of writing".
- GLIB section 1 heading says "65/72"; should be 72/72.

### 5. GEO verification numbers do not reproduce (conclusion holds)

| Check | Audit | Documented |
|---|---|---|
| Plane 3 shared-wall agreement, horizontal/vertical | 99.6/99.7 | 96.5/97.5 |
| Planes 0/1 in documented order | 100/100 | not stated here |

The best wrong ordering reaches at most 0.57 on the vertical axis and ties on the horizontal axis (a
N/S swap is invisible to a horizontal check). The documented "best of the other 23 permutations
55.7%" does not reproduce. Replace with script-backed numbers.

## Unverified / open

- **Palettes (untracked).** 56 B palette blocks (8-byte header + 16 RGB888 triplets) in Secret
  `DISK2/PIC.TLB`; unverified against screenshots (hypothesis). Row `goldbox-glib-palette`.
- **Compressed images.** HEAD, BODY, PIC, SPRIT and BIGPIC blocks have header byte 7 = `0x02` and
  sizes that do not fit raw planes; likely individually compressed images
  (`goldbox-glib-compressed-images`).
- No row for SOUNDS (`DIG8`), STRINGS (`TEXT`), `.FON`, `SLBR`/`MXTX` music, or ITEMS.DAT (2,048 B,
  a different MD5 per GLIB title).
- Not re-checked: Pools v1.3 opcode table, CFG-walk counts, plane 2 meaning.

## Recommended corrections, cheapest/highest value first

1. Glyph decoder fix and re-render (finding 1).
2. Fix stale text (findings 2 and 4) and GEO numbers (finding 5).
3. Test the slot-fill rule on levels 16 and 80-82 (finding 3).
4. Wire GLIB palette blocks into output.
5. Add rows `goldbox-glyph-format`, `goldbox-glib-palette`, `goldbox-ecl-multiwallset-slotfill`,
   `goldbox-glib-compressed-images`.
