# Dungeon Hack

Dungeon Hack shares the AESOP/16 lineage with EOB3 but has its own resource
corpus and generated-dungeon scope. The container, old-format bitmaps,
palettes and proportional font are confirmed against the released AESOP
interpreter and DAESOP material.
