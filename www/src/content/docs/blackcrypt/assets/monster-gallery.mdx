# Monster Gallery

All **204** distinct monster sprites from `bcdfb` through `bcdfn`, grouped by
creature — every one of the 26 clusters now carries a real, confirmed name.
Each card cycles through that creature's stored size/depth ladder; hover a
card to pause it. Names come from the game's manual, clue book, and ending
text, or — for the majority, since no in-game bestiary table exists on the
Amiga side — from the Windows demo's own `crypt.exe`, which shares the same
creature-ID space and turned out to carry the developer's own names for
every creature outright.
