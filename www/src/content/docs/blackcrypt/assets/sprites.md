# Sprites

The extracted sprite atlases, served from `/assets/blackcrypt/amiga/sprites/`.
Each atlas is a single PNG plus a JSON manifest describing frame geometry and
palette. They're rendered in greyscale unless the palette is confirmed.

For frame-by-frame browsing, use the dedicated show-and-tell galleries:

- [All monsters](/blackcrypt/assets/monster-gallery/)
- [All inventory items](/blackcrypt/assets/item-gallery/)
- [All floor items](/blackcrypt/assets/floor-item-gallery/)
- [All spell effects](/blackcrypt/assets/effect-gallery/)
- [All portraits](/blackcrypt/assets/portrait-gallery/)
- [Keys, projectiles, decorations and equipment art](/blackcrypt/assets/other-sprite-galleries/)

## Monsters (from `bcdfb`–`bcdfn`)

204 monster sprites across all 13 dungeon levels, byte-exact.

## Item icons (from `bcdfa`)

180 item icons — 24×24, 6bpp, no mask.
